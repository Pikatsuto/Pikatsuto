## 👨‍💻 Qui suis-je

Je suis **Gabriel Guillou**, administrateur systèmes Linux orienté virtualisation, exploitation et automatisation.

Je développe et maintiens **[DaemonCores](https://github.com/DaemonCores)**, un projet solo qui apporte le modèle immuable bootc/OSTree à Debian : images système OCI signées, paquets Debian, Secure Boot, et une CI qui teste le démarrage de chaque image avant de la publier.

## 🚀 Projets phares

- **[debian-bootc](https://github.com/DaemonCores/debian-bootc)** - Debian 13 en image bootc/OSTree : pile bootc empaquetée pour Debian, GRUB BLS signé pour Secure Boot, ISO d'installation en ligne et hors ligne
- **[DaemonCores-VE](https://github.com/DaemonCores/DaemonCores-VE)** - Proxmox VE en image transactionnelle, avec un plugin de stockage Proxmox qui exécute des images OCI en conteneurs LXC immuables et un convertisseur Docker Compose vers Podman/Quadlet
- **[DaemonCores-CI](https://github.com/DaemonCores/DaemonCores-CI)** - Pipeline GitHub Actions mutualisé : builds amd64/arm64, dépôts APT signés, tests de démarrage QEMU/KVM avant publication
- **[DaemonCores-Phone](https://github.com/DaemonCores/DaemonCores-Phone)** - R&D : base Debian/bootc pour smartphones et schéma de description d'appareils
